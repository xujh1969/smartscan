# 小模型路线评估（2026-11-14）

目标是找到纸面上的每一张照片，而不是分割照片内容中的人物、水面或建筑。模型通用分割能力强，不等于能自动区分本项目中的照片边界。

| 候选 | 适合尝试的方式 | 本项目验证状态 |
| --- | --- | --- |
| MobileSAM | 用较可靠的照片框提示后细化边界 | 本机做过小规模点提示及已有框方案试验；会取到照片内物体，或合并整组，没有证明足以直接替换当前检测 |
| SAM 2.1 Tiny | 对选中的单张候选照片进行提示分割，之后拟合四边形 | 官方有 Tiny 权重及交互分割接口；尚未在这 43 张扫描件上实测，不承诺明显提升 |
| FastSAM-s | 快速产生多个掩膜，再根据照片形状和边界证据筛选 | 官方提供基于 YOLOv8s 的较小版本；尚未在本项目实测，仍需排除照片内部对象 |
| 小型 OBB 旋转框检测器 | 用本任务的照片边界标注微调，直接输出单张照片框和角度 | 更贴合矩形照片的工程方向；尚未训练或验证。官方 YOLO26n-obb 参数表为约 2.4M，但其现成预训练任务不是扫描照片拆分，不能直接视为可用效果 |

建议先完成可靠的校正流程，再用已确认的框建立标注与独立验收集，对比小型旋转框检测器和 SAM 2.1 Tiny 提示细化。这个建议是对任务匹配程度的推断，不是已测得的准确率提升。评估应按源扫描件划分训练/验收，避免同一照片的近重复片段进入两边；分别统计漏拆、误切、合并和边界偏移。

本版只保存本机框坐标，没有上传照片、训练模型或增加模型运行依赖。
