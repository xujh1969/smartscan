# SmartScan

> 把「一次平铺扫描了多张老照片」得到的大图，自动拆成一张张独立的、已扶正的单张 PNG。
> 全程图形界面、离线运行，不缩放、不二次压缩、不改动原扫描件。

## 为什么需要它

为了省时间，很多人会把好几张老照片一起平铺在扫描仪上扫描。结果是得到一张大图，还得手工把每张照片裁出来、摆正、判断横竖、逐张保存——几百张照片时这项工作非常耗时。SmartScan 先自动识别候选框，再提供可保存的人工校正：检查边界、补框或删框、预览并调整方向，最后一次性批量导出。

## 最新版本：v1.2.1（2026-11-15）

- 左侧选择扫描图，中间编辑裁切框，右侧预览裁切结果并预设顺、逆时针旋转；最后一次性批量导出。
- 修复 `<`、`>` 按钮随画布移动的问题：按钮固定在预览区左右中线，滚轮缩放、空格/中键平移及窗口缩放后保持位置。

- 关闭未完成的工作时可继续、保存退出或不保存退出；Ctrl+Z 支持裁切框与旋转撤销。
- 本机 147 项测试、GUI 启动/退出及 Python 编译检查通过。真实照片仍需人工检查漏框和误框，不能保证全自动拆分准确率。

## 主要功能

- **批量导入**：一次选择任意多个目录下的扫描图（支持拖拽），统一输出到一个目录。
- **自动拆分**：优先用局部浅色纸边和窄间隙分区，保留各张照片的外轮廓；没有纸边证据时使用几何检测，并对不确定的拆分标记待复核。水面、建筑等照片内部长直线不再单独作为可靠切缝。
- **自动扶正**：拟合每张照片的旋转矩形，做且只做一次 Lanczos 旋转，默认四角用扫描背景色填充。不规则四边形自动采用内接矩形裁切，不做透视拉伸，但会舍去部分边缘；旋转矩形保留所选的四角处理方式。
- **裁切框预览与校正**：在原图上用鼠标拖动四角、绘制新框、删除错框；滚轮缩放，按住空格拖动或中键拖动可平移，松开空格立即恢复编辑，框与原图同步显示。右侧单列显示裁切后的预览，每张图片上有顺、逆时针 90° 旋转图标。裁切框和旋转设置一起保存，Ctrl+Z 也可撤销旋转；最后按预置裁切与方向批量导出。
- **未完成退出提醒**：关闭主程序时若工作尚未完成，提供「继续工作」「保存并退出」「不保存并退出」，默认继续。保存退出会保存当前裁切框与旋转设置；不保存退出丢弃当前未保存的编辑，保留此前已保存设置与已导出文件。后台任务均等待当前扫描图保存完成后安全停止；保存失败则保留窗口与编辑。
- **重叠处理**：上层照片完整输出；被压住的照片输出可见部分并标 `incomplete`；判断不可靠时标 `uncertain`。宁可误报、不静默丢照片。
- **方向判定**：已校正的扫描图按照右侧预览的方向导出，自动方向判定不会覆盖预设。直接自动拆分时使用离线传统图像特征保守投票，只有多个信号一致且高置信度才自动转 90°；判不准保持原样并标 `unknown`。
- **预览与旋转**：缩略图网格、角标筛选、每张照片上顺/逆时针 90° 两个按钮、多选批量旋转与快捷键；点击后后台自动存盘。旋转始终从首次拆分结果出发，反复点击不会累积画质损失。
- **清晰度和元数据**：输出统一 PNG；不缩放、不自动增强、不二次压缩；原图 DPI (`pHYs`)、ICC (`iCCP`) 与来源/裁切/角度/旋转状态 (`tEXt`) 都写在 PNG 自身。
- **可重复运行**：按「完整源路径 + 内容哈希 + 检测版本」识别已完成文件，同版重跑跳过、**永不覆盖**；升级检测算法后可重新处理旧版结果；原扫描件全程只读。
- **纯 GUI**：没有命令行交互，不需要联网，可打包成单文件 Windows exe。

## 快速开始

环境：Windows + Python 3.11+（本次验证为 Python 3.11、PySide6 6.9.3）。

**双击启动（推荐）**：直接双击项目根目录的 `run.bat`。首次运行会自动检查并安装依赖（仅首次需要联网），之后直接打开图形界面，不会弹出控制台窗口；不需要记任何命令。

命令行等价方式（也是开发调试入口）：

```powershell
git clone https://github.com/xujh1969/smartscan.git
cd smartscan
python -m pip install -r requirements.txt
python run.py
```

若程序启动异常，可在命令行执行 `python run.py` 查看报错；`run.bat --smoke` 用于无界面自检。

### 使用流程

1. **选择**：添加一批扫描图（可跨目录、可拖拽），指定结果目录，按需调整倾角上限与四角处理方式，点「开始拆分处理」。
2. **校正（推荐）**：点「预览、校正裁切框，再批量裁切」。顶部工具栏集中放置绘制、删除、撤销与适应窗口按钮，操作说明可悬停查看。点选框后拖动四角；点「绘制新框」并拖动可补框，画完自动选中新框并恢复编辑；Esc 取消尚未完成的绘制，保留已有框。Delete 删除选中的框，Ctrl+Z 逐步撤销新增、删除和角点调整（一次拖动算一步）；保存后仍可撤销，切换扫描图时清空撤销历史。滚轮缩放，按住空格拖动或中键拖动可移动图片，松开空格立即恢复角点编辑，框始终使用原图坐标。
3. **逐张校正，再批量裁切**：左侧单列缩略图栏显示所有已添加的扫描图，可滚动并点击任意图片，当前图片以灰底和蓝色框线标记；预览区左右中央的圆形 `<`、`>` 按钮用于上一张、下一张，悬停显示边框。单击缩略图会先结束当前拖动、保存当前框再跳转，重复点击已选中缩略图也会尝试打开；保存失败保留当前图片。顶部显示「扫描图 1 / N」。若显示「1 / 1」，请点「返回选择扫描图」，在添加图片对话框中按 Ctrl+A 或 Ctrl 多选。最后点击底部「保存并批量裁切」，只处理已保存的扫描图，未访问且未保存的图片不会被偷偷确认。已保存的零个框表示本张不输出照片。预览窗口会适配屏幕大小，也可最大化。
4. **进度与结果**：查看逐文件进度，可随时取消；结果页支持顺/逆 90°、多选批量旋转及 `]` / `[` 快捷键，双击查看大图与元数据。原始照片朝向无法判定时仍需手动旋转。

画好框后，可先在右侧预览上点击顺、逆时针旋转图标调整方向，再点击「保存并批量裁切」。框修改后预览会更新；删框及撤销时旋转设置跟随对应的照片。预览使用缩小图，最终导出仍读取原始扫描件；90° 旋转仅重排像素。结果页仍可进行导出后的旋转。

校正框与旋转设置保存在 `%LOCALAPPDATA%\SmartScan\reviews\`，按扫描件完整内容哈希与尺寸识别，兼容旧版裁切框（初始旋转为 0°）。源文件被替换后旧框失效；编辑期间原图变化也会阻止错误保存。改框或改预设方向后可以重导出且不会覆盖旧结果；同版同框同方向重复导出跳过，校正导出中断或丢失部分文件时会补齐缺失照片。

### 输出约定

| 项 | 约定 |
|---|---|
| 位置 | 用户指定的**一个**目录，所有结果平铺其中，不建子目录、不放日志/manifest |
| 格式 | 统一 PNG（无损），输入可为 JPEG / TIFF / BMP / PNG |
| 命名 | `<三位全局序号>_<8位内容哈希>.png`，例如 `001_a3f2c1b9.png` |
| 元数据 | `tEXt`：完整源路径、内容哈希、裁切框、扶正角、旋转状态、置信度、标记；`pHYs`：原 DPI；`iCCP`：原 ICC |
| 画质 | 不缩放、不自动增强；仅扶正时一次重采样；90° 旋转为无损像素重排 |
| 四角 | 矩形（含旋转矩形）默认背景色填充，也可选择内接或透明；不规则四边形自动内接裁切，会损失部分边缘 |

## 实现概要

```
扫描图 ──> 估计扫描背景 ──> 局部纸边/间隙 ──> 独立轮廓 ──> 旋转矩形
                     └─> 缺乏纸边证据 ──> 几何候选 + 待复核
候选框 ──> 四角人工校正 + 右侧预览/方向预设 ──> 保存，最后批量导出
每张照片 ──> 一次 Lanczos 扶正 + 四角处理 ──> 保存的方向预设（直接自动拆分时保守投票）
                                               └─> 原子写 PNG（含元数据）
```

关键点是**识别纸张边界，而不是照片内容中的分界线**。强直线可能是水面、栏杆或建筑边缘。前景掩膜只负责定位，不能用于擦除照片内部的浅色内容。领域模块（`smartscan/*.py`）不依赖 Qt，可以脱离界面做单元测试。

## 项目结构

```

run.py                       GUI 入口
requirements.txt             依赖清单
smartscan/
  models.py                  共享数据类
  geometry.py                四边形 / 倾角 / 内接矩形
  detection.py               背景估计、接缝检测、遮挡推理
  boundaries.py              局部纸边分区、轮廓与扫描杂线处理
  split.py                   裁切 + 一次扶正 + 四角填充
  orientation.py             保守方向投票
  rotation.py                90° 无损旋转与落盘
  review.py                  校正框校验、内容身份、原子保存与修订标识
  naming.py / metadata.py    命名、PNG 元数据、原子写盘
  pipeline.py                批处理编排、取消、重跑跳过
  gui/                       三页界面（选择 / 进度 / 结果预览）
    review_dialog.py         裁切框编辑、缩放平移、后台初始识别与批量确认
    crop_preview.py          右侧裁切预览与顺、逆时针旋转图标
tests/                       单元测试 + 合成扫描图 + offscreen GUI 测试
scripts/verify_samples.py    真实扫描件验收工具（开发用）
docs/                        设计规格与实施计划
```

## 开发与测试

```powershell
python -m pytest tests/ -q
$env:QT_QPA_PLATFORM = "offscreen"; python run.py --smoke
python -m compileall -q smartscan
```

本次新增照片内部水面/建筑线条、浅色内容保留、背景估计、错位排列、竖幅倾角和旧版结果重处理回归测试。另有 3 个本机私有扫描件回归，未携带样本时会跳过；测试通过不能替代真实拆分效果验收。

用真实扫描件做一次本地验收（结果写在本机 `verify_output/`，**不会提交到仓库**）：

```powershell
python scripts/verify_samples.py --dir "D:\你的扫描件目录" --clean
```

脚本默认读取本项目的 `扫描/`，生成 `verify_index.png`（结果缩略图索引）、`verify_output_report.json`（逐张明细、每个来源的输出数）与 `verify_output/photos/`（拆分结果），方便核对漏拆、误切与朝向。输出数是候选文件数，不代表准确率。

## 已知限制（v1）

- 仅自动处理 8bit/通道的 L / RGB / RGBA 输入；更高位深不降位深输出，记为失败并提示人工处理。
- 与扫描背景同色的白边不单独保留（照片本体不受影响）。
- 裁切框编辑入口在选择页；结果页只调整输出朝向。删除候选框不会删除原扫描件或已有输出文件。
- 自动方向判定刻意保守，判不准的标 `unknown` 交人工确认；不做 180° 自动判定（点两次 ±90° 即可）。
- 对本机 43 张扫描件进行了新旧检测对比。纸边清楚的密集摆放和单张人像、合影的碎切明显减少；无白边紧贴的照片仍有漏拆，浅色照片也可能定位到内容而不是完整纸边。目前不能宣称已达到高成功率全自动。详见 `docs/2026-11-14-detection-validation.md`。
- v1.2.1 的 147 项测试、GUI 启动和退出检查通过，包含缩放/平移后的固定翻页位置、异步缩略图完整点击区域、裁切预览、每框旋转预设保存/恢复/撤销/导出、不保存退出、逐步撤销及快捷键操作。真实第 28 张扫描件已通过 Qt 鼠标事件测试完成删错框、画四框、调四角、保存重开与四张原分辨率 PNG 导出，原图未变。原生窗口已检查到预览显示，完整原生鼠标操作仍需用户试用；上述全流程交互验证采用 offscreen Qt。
- 小模型候选及试验边界见 `docs/2026-11-14-small-model-assessment.md`。本版没有引入未经本批照片验证的模型。
