# SmartScan

> 把「一次平铺扫描了多张老照片」得到的大图，自动拆成一张张独立的、已扶正的单张 PNG。
> 全程图形界面、离线运行，不缩放、不二次压缩、不改动原扫描件。

## 为什么需要它

为了省时间，很多人会把好几张老照片一起平铺在扫描仪上扫描。结果是得到一张大图，还得手工把每张照片裁出来、摆正、判断横竖、逐张保存——几百张照片时这项工作非常耗时。SmartScan 把这条流程自动化：选一批扫描图、指定一个输出目录、点开始，然后在预览页里把方向不对的照片点两下即可。

## 主要功能

- **批量导入**：一次选择任意多个目录下的扫描图（支持拖拽），统一输出到一个目录。
- **自动拆分**：面向「照片紧贴、多数无白边、彼此有轻微倾斜、少量压角重叠」的真实摆放方式，用扫描背景差分 + 连续长直线段接缝检测定位每张照片。
- **自动扶正**：拟合每张照片的旋转矩形，做且只做一次 Lanczos 旋转，四角用扫描背景色填充，不切掉照片内容。
- **重叠处理**：上层照片完整输出；被压住的照片输出可见部分并标 `incomplete`；判断不可靠时标 `uncertain`。宁可误报、不静默丢照片。
- **方向判定**：全离线传统图像特征保守投票，只有多个信号一致且高置信度才自动转 90°；判不准保持原样并标 `unknown`。
- **预览与旋转**：缩略图网格、角标筛选、每张照片上顺/逆时针 90° 两个按钮、多选批量旋转与快捷键；点击后后台自动存盘。旋转始终从首次拆分结果出发，反复点击不会累积画质损失。
- **清晰度和元数据**：输出统一 PNG；不缩放、不自动增强、不二次压缩；原图 DPI (`pHYs`)、ICC (`iCCP`) 与来源/裁切/角度/旋转状态 (`tEXt`) 都写在 PNG 自身。
- **可重复运行**：按「完整源路径 + 内容哈希」识别已完成文件，重跑跳过、**永不覆盖**；取消后已完成结果保留；原扫描件全程只读。
- **纯 GUI**：没有命令行交互，不需要联网，可打包成单文件 Windows exe。

## 快速开始

环境：Windows + Python 3.11+（开发验证环境为 Python 3.14）。

```powershell
git clone https://github.com/xujh1969/smartscan.git
cd smartscan
python -m pip install -r requirements.txt
python run.py
```

### 使用流程

1. **选择**：添加一批扫描图（可跨目录、可拖拽），指定结果目录，按需调整倾角上限与四角处理方式，点「开始拆分处理」。
2. **进度**：查看逐文件进度与阶段，可随时取消；已落盘的结果保留。
3. **结果预览**：缩略图网格按 `incomplete` / `uncertain` / `unknown` / `auto` 等角标筛选；每张照片上有「顺 90°」「逆 90°」按钮，也可勾选多张一键批量旋转（`]` / `[` 快捷键）；双击查看放大图与元数据。磁盘写入成功后缩略图才会刷新。

### 输出约定

| 项 | 约定 |
|---|---|
| 位置 | 用户指定的**一个**目录，所有结果平铺其中，不建子目录、不放日志/manifest |
| 格式 | 统一 PNG（无损），输入可为 JPEG / TIFF / BMP / PNG |
| 命名 | `<三位全局序号>_<8位内容哈希>.png`，例如 `001_a3f2c1b9.png` |
| 元数据 | `tEXt`：完整源路径、内容哈希、裁切框、扶正角、旋转状态、置信度、标记；`pHYs`：原 DPI；`iCCP`：原 ICC |
| 画质 | 不缩放、不自动增强；仅扶正时一次重采样；90° 旋转为无损像素重排 |
| 四角 | 默认用扫描背景色填充；也可切换「内接裁切」或「透明四角」 |

## 实现概要

```
扫描图 ──> 估计背景色 ──> 前景照片簇（连通域）
                     └─> Canny + Hough 连续长直线段 ──> 行/列接缝投影
                                                 └─> 网格单元 ──> 实心主体裁剪
                                                              └─> 最小外接矩形（含倾角）
每张照片 ──> 一次 Lanczos 扶正 + 背景填充 ──> 保守方向投票 ──> 原子写 PNG（含元数据）
```

关键点是**不能用颜色/亮度聚类区分照片**：真实老照片内部有大量不同色块，聚类会把一张照片打成碎片。只有贯穿整张照片的连续长直线（接缝、纸边）才是可靠证据。领域模块（`smartscan/*.py`）不依赖 Qt，因此可以脱离界面做单元测试。

## 项目结构

```
run.py                       GUI 入口
requirements.txt             依赖清单
smartscan/
  models.py                  共享数据类
  geometry.py                四边形 / 倾角 / 内接矩形
  detection.py               背景估计、接缝检测、遮挡推理
  split.py                   裁切 + 一次扶正 + 四角填充
  orientation.py             保守方向投票
  rotation.py                90° 无损旋转与落盘
  naming.py / metadata.py    命名、PNG 元数据、原子写盘
  pipeline.py                批处理编排、取消、重跑跳过
  gui/                       三页界面（选择 / 进度 / 结果预览）
tests/                       单元测试 + 合成扫描图 + offscreen GUI 测试
scripts/verify_samples.py    真实扫描件验收工具（开发用）
docs/                        设计规格与实施计划
```

## 开发与测试

```powershell
python -m pytest tests/ -q
$env:QT_QPA_PLATFORM = "offscreen"; python run.py --smoke
python -m compileall -q smartscan
```

当前状态：`57 passed`，GUI 冒烟通过。GUI 使用 offscreen 平台做自动化验证；领域模块可在无显示环境单测。

用真实扫描件做一次本地验收（结果写在本机 `verify_output/`，**不会提交到仓库**）：

```powershell
python scripts/verify_samples.py --dir "D:\你的扫描件目录" --clean
```

脚本会生成 `verify_index.png`（结果缩略图索引）、`verify_output_report.json`（逐张明细）与 `verify_output/`（拆分结果），方便人工核对召回、裁切与朝向。

## 已知限制（v1）

- 仅自动处理 8bit/通道的 L / RGB / RGBA 输入；更高位深不降位深输出，记为失败并提示人工处理。
- 与扫描背景同色的白边不单独保留（照片本体不受影响）。
- 结果页不提供手动补框、单张删除、单张重拆；待复核/失败文件在进度页汇总，日志位于 `%LOCALAPPDATA%\SmartScan\logs\smartscan.log`。
- 自动方向判定刻意保守，判不准的标 `unknown` 交人工确认；不做 180° 自动判定（点两次 ±90° 即可）。
- 已完成 9 张 2550×3508 @300dpi 真实扫描件验收：约 13 秒输出 35 张 PNG、失败 0、5 个源文件因超倾角进待复核；多数照片拆分正确。仍有少量空白块误检与极小碎片、个别 2×2 拼贴未完全切开、个别照片横躺需 ±90° 纠正。这是「召回优先」策略的已知取舍。
